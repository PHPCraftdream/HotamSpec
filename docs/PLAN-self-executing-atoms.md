# PLAN: самоисполняемые атомы — метод сам несёт свой текст

Дата: 2026-10-01
Основание: разбор домена `apps/Human` — у одного факта сейчас четыре текста в трёх местах (doc-комментарий метода, заголовок сценария, метка `Eq`, строка в реестре), связи `implemented_by`/`verified_by` пишутся строками руками, а большая спека упирается в плоский реестр, ручной `DeclOrder`, полный прогон тестов на каждый рендер и «всё или ничего» в CLAUDE.md.
Статус: Ф0–Ф6 реализованы; приёмка Human и полный `go test -timeout 30m ./...` пройдены. Исходный год рождения 1987 восстановлен после проверки 1987 → 1988.

## Принцип

Объект, поля, методы. Метод — атом: минимальный, одно выражение. Его doc-фраза плюс исполненное значение и есть текст требования; тест исполняет метод и этим же порождает текст. Модели хватает одного взгляда на пару «метод + одна строка теста», чтобы убедиться, что тест соответствует коду.

Один факт = doc-фраза + метод + одна строка теста:

```go
// год рождения
func (h Human) BirthYear() BirthYear { return h.born }

func TestBirthYear(t *testing.T) {
	hotamspec.Fact(t, Init().BirthYear, BirthYear(1987))
}
```

→ «Год рождения — 1987.» Ручного заголовка нет, расхождению негде взяться.

## Критерий приёмки (на Human)

- Смена 1987 → 1988 правкой `Init` и `want` в тесте меняет текст в SPEC.md и CLAUDE.md без других правок.
- `requirements.go` содержит только REJECTED и редкие переопределения.
- `hotam all-violations` = 0; полный `go test ./...` зелёный.

## Не цели

- Семантическая проверка «тест доказывает текст» — остаётся за зеркальным аудитом (граница из `internal/invariants/authored_links.go`).
- Удаление `NewScenario`: он остаётся для многошаговых сценариев.
- Собственный дисковый кэш вердиктов (сознательно удалён в b014a63).

## Фазы

### Ф0. Контракт
`docs/AUTHORED-SPEC-CONTRACT.md` §9: атом = метод; фраза = первая строка doc-комментария; текст = фраза + исполненное значение; отношение = отдельный `bool`-метод с доказательствами-фактами. Новый режим включается по домену, старые домены не ломаются.

### Ф1. Рекордер (`internal/recorder/canon/hotamspec.go`)
- `hotamspec.Fact(t, method, want)` — один факт, один метод.
- `hotamspec.Holds(t, predicate, evidence...)` — отношение.
- Субъект (`model.Human.BirthYear`) узнаётся в рантайме через `runtime.FuncForPC`, нормализуется (суффикс `-fm`, указатели, дженерики) и пишется в артефакт как `Subject` вместе с отрендеренным значением.
- Замыкания и анонимные функции — ошибка: им нельзя сопоставить метод в коде.

### Ф2. Текст из кода (`internal/selfspec/claim_derive.go`, `cmd/hotam/sync_domain.go`)
- По `Subject` через AST берётся doc-фраза метода, Claim = «Фраза — значение.».
- Ручной заголовок не нужен; заданный заголовок, расходящийся с собранным текстом, — нарушение.

### Ф3. Связи и реестр выводятся
- `implemented_by` = объединение `Subject` всех шагов теста; `verified_by` = сам тест.
- Owner/status по умолчанию — из манифеста домена; реестр — только переопределения и REJECTED.
- `authored_links` проверяет уже вычисленные ссылки без изменений.

### Ф4. Инварианты атомарности (`internal/invariants/`)
- `check_fact_method_has_phrase` — у метода-субъекта есть doc-фраза.
- `check_fact_method_atomic` — тело метода одно выражение; ветвления только у методов-отношений.
- `check_one_subject_per_fact` — один `Fact` проверяет ровно один метод.
- Только структурные проверки.

### Ф5. Масштаб
- Пакет на поддомен (`spec/model/<sub>/`); `sync-domain` обходит всё дерево.
- Порядок требований — позиция в коде; `DeclOrder` не нужен.
- SPEC.md шардируется по пакетам (`docs/gen/spec/<pkg>.md`) с индексом.
- CLAUDE.md: при превышении бюджета 6000 символов — оглавление по пакетам со счётчиками вместо пустоты.
- Прогон только изменённых пакетов с родным кэшем `go test`; закрывает #23 без собственного кэша вердиктов.

### Ф6. Миграция и документация
- `apps/Human` переводится на `Fact`/`Holds`; `ActuallyMatchesRole` и `ByTorahNotJewish` — через `Holds`.
- `docs/QUICKSTART-CONSUMER.md`, consumer-кристалл (How to change), `README.md`.

## Порядок

Ф0 → Ф1 → Ф2 → Ф3 → Ф6. Ф4 и Ф5 параллельно после Ф1.

## Риски

- Имена методов-значений в рантайме (`-fm`, указатели, дженерики) — нужна нормализация с тестами.
- Несколько методов в одном `Fact` противоречат атомарности — запрещать или требовать `Holds`.
- Переименование метода при выводимом ID превращается в новое требование + REJECTED с `replaces`.

## Принятые решения

1. ID требования выводится из метода (`R-human-birth-year`); явные переопределения остаются для исторических якорей.
2. Метод значения содержит один `return` с одним выражением; ветвления допустимы у `bool`-отношений `Holds`.
3. #23 закрыт родным кэшем `go test`: пакетные артефакты воспроизводятся из stdout, покрытие конкретного теста восстанавливает сам Go. Собственного дискового кэша вердиктов нет. Старый worktree сохранён: в нём есть незакоммиченная идея инвалидации скомпилированных бинарников, которую нельзя терять вместе с отвергнутым дисковым кэшем.
